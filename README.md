# Instituto Seven – Site Oficial

Projeto desenvolvido como entrega final da disciplina, com foco em **versionamento profissional, acessibilidade (WCAG 2.1)** e **otimização para produção**.

---

## Objetivos do Projeto
Este projeto tem como objetivo aplicar práticas reais de desenvolvimento web moderno, incluindo:
- Estrutura de **Single Page Application (SPA)**;
- Organização de **HTML, CSS e JavaScript** em branches separadas;
- Controle de versão com **GitFlow**;
- Implementação de **acessibilidade conforme WCAG 2.1 Nível AA**;
- Otimização de desempenho e deploy em ambiente de produção.

---

## Estrutura do Projeto

| Branch | Descrição |
|--------|------------|
| `main` | Estrutura HTML e documentação (README) |
| `css` | Estilos e layout (CSS) |
| `js` | Scripts e interatividade (JavaScript) |

---

## Tecnologias Utilizadas
- **HTML5** – Estrutura semântica e acessível  
- **CSS3** – Estilos responsivos e versão de alto contraste  
- **JavaScript (ES6+)** – Funcionalidades dinâmicas e navegação  
- **Git/GitHub** – Versionamento e gerenciamento de branches  
- **WCAG 2.1** – Diretrizes de acessibilidade Nível AA  

---

## Acessibilidade Implementada
- Navegação completa por teclado  
- Estrutura semântica de cabeçalhos e landmarks  
- Contraste mínimo de 4.5:1  
- Compatibilidade com leitores de tela  
- Modo de **alto contraste** e **modo escuro acessível**

---

## Otimização para Produção
- Minificação de arquivos **HTML**, **CSS** e **JavaScript**  
- Compressão e otimização de imagens  
- Organização de assets para carregamento eficiente  

---

## Controle de Versão (GitFlow)
Fluxo aplicado:
1. **`main`** – versão estável do projeto  
2. **`develop`** – ambiente de integração (opcional)  
3. **`css`**, **`js`** – branches de funcionalidades  
4. Pull Requests e merges documentados  
5. **Release criada:** [`v1.0.0`](https://github.com/JessicaNeves-S/Instituto-Seven-Site/releases/tag/v1.0.0)

---
